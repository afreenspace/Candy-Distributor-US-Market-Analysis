# Contributing

Thank you for contributing to the Candy Distributor — US Market Analysis project.

Guidelines
- Keep code and SQL tidy and well-commented.
- Do not commit large data files into the repository. Use `data/` or `exports/` if needed and add them to `.gitignore`.
- Use clear commit messages (see examples below).

Commit message examples
- `chore: add README and analysis SQL`
- `feat: add monthly trend analysis query`
- `fix: correct column name in profit margin query`

Pull requests
- Open a PR to `main` with a short summary of changes and any query outputs attached.
- Include screenshots in `docs/screenshots/` when relevant.
